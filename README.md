# Bike Buyers Analysis Dashboard

## Project Overview
This project uses Microsoft Excel to analyse customer data and understand the factors associated with bike purchases.

## Objectives
- Analyse bike purchases by gender and age group.
- Explore the relationship between income and bike purchases.
- Compare bike purchasing patterns across regions.
- Present key findings in an interactive Excel dashboard.

## Tools Used
- Microsoft Excel
- PivotTables
- PivotCharts
- Slicers
- KPI cards

## Key Metrics
- **Total Customers:** 1,000
- **Total Bike Buyers:** 481
- **Bike Purchase Rate:** 48.1%
- **Average Customer Age:** 44.16 years

## Project Process
1. Cleaned and prepared the dataset.
2. Created PivotTables to summarise customer data.
3. Built charts to explore purchasing patterns.
4. Created KPI cards for key metrics.
5. Developed a dashboard to present the analysis.

## Files
- Excel workbook: Bike Buyers Analysis Dashboard

## Conclusion
This dashboard provides a summary of customer bike purchasing patterns and helps explore which customer groups are more likely to purchase bikes.
